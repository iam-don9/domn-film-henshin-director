## 1. 十九个亚类谱系

| # | 亚类 | 定义 | 核心看点 | 最容易写砸 |
|---|---|---|---|---|
| 1 | **着装装甲化**<br>Henshin suit | 借装置/咒语在**身体外**覆上战斗服与装甲，本体不变（含 ①-A 魔法少女型与 ①-B 装甲骑士型，见 §1.1） | 部件依次咬合 / 装饰物遮盖替换的仪式感、装备登场 | 光效堆砌，没有"穿上去"的咬合逻辑 |
| **2** | **兽化**<br>Beast-form | 人→**兽 / 兽人**。有机生物重构：骨骼延展、肌肉膨胀、毛发刺出、体型比例改变 | 生物性重构的张力与生长感——**是身体本身在改** | 用粒子/光代替重构（那是⑮能量重铸）；或过度写实滑向恐怖片 |
| **3** | **物件化**<br>Object-form | 人→**无生命器物**（武器 / 家具 / 器械 / 日常物品）。无机化：材质置换 + 几何化 + 段落刚性化 | 人正在变成"某种材料"的置换感；终点是静止器物 | 写成机械变形（④）；或材质替换边界不可见，变成"贴了层皮" |
| 4 | **机械变形** | **无机→无机**：结构翻转重组（载具↔机器人） | 结构可信的连续变形、零件咬合次序 | 变形步骤跳帧，中间态不可信 |
| 5 | **物品→人形** | 器物获得灵性/生命化成类人（③物件化的**逆过程**） | 器物特征拟人化（腰带化人、伞化人） | 器物特征丢失，变成普通人在发光 |
| 6 | **兽→高阶兽（进化）** | 同物种沿等级阶梯升级 | 挣脱旧壳的升阶感、等级跃迁 | 每阶外观无差异，审美疲劳 |
| 7 | **合体** | ≥2 个独立体物理融合为更强整体 | 部件归位时序、对接咬合的机械爽感 | 组合瞬间穿帮、比例失调 |
| 8 | **巨大化** | 体积尺度放大（人→巨像） | 尺度压迫感 | 与环境尺度失配（不够大 or 场景没反应） |
| 9 | **退化 / 幼化** | 沿发育轴逆向变小/变弱 | 能力落差的反差与情感 | 只缩不放情感戏，变成纯噱头 |
| 10 | **性别转换** | 生理性别切换 | 身份错位的戏剧/喜剧张力 | 只换皮，行为与气质没跟上 |
| 11 | **附身 / 被附身** | 外来意识占据或共享身体 | 控制权拉锯、身体异变 | 宿主完全被动，没有挣扎与争夺 |
| 12 | **多段阶进** | 同一体系逐级解锁更强形态 | 解锁爽感、代价递增 | 阶数过多，视觉语言无法区分 |
| 13 | **纯换装** | 仅服装瞬时更替，**零身体改造** | 时尚舞台感、织物生成方式 | 无身体变化导致"假变身"，观感廉价 |
| 14 | **拟态 / 易容** | 主动改外貌伪装成他人 | 伪装与揭穿的悬念 | 变形过程被省略，失去真实感 |
| 15 | **能量重铸** | 身体解构为粒子/光再重铸成形 | 解构—重铸的诗意与壮观 | 只剩一团光球，没有结构信息 |
| 16 | **机械融合 / 赛博格化** | 有机体局部替换为机械 | 人机边界的质感对比 | 机械部件没有功能逻辑，像贴上去的 |
| 17 | **分身增殖** | 主体复制出多个自身 | 数量压制的调度 | 分身质感不一致、数量穿帮 |
| 18 | **形态解放** | 封印/潜能释放为强化态 | 封印破碎的爆发 | 解放前后形态语言没有关联 |
| 19 | **恐怖异化**<br>Horror / body-horror | 身体在**违背意志**下被侵蚀、重构为恐怖存在，**自我逐渐丧失**（感染 / 诅咒 / 实验事故 / 寄生） | **不可控的侵蚀感**——观众和角色一起"看着自己变成别的东西" | 要么恶心到没法看（纯血肉堆砌），要么不够恐怖（只换皮）。强度分级见 `05 §5.1` |

### 1.0 ②兽化 与 ③物件化 的分野（原为同一格，现已拆分）

两者都是"本体形态根本改变"，但**形态构建的语法完全相反**：

| | **② 兽化** | **③ 物件化** |
|---|---|---|
| 变化方向 | 有机 → 另一种**有机** | 有机 → **无机** |
| 材料 | 身体的生物材料（骨、肉、毛、爪、牙） | 被置换成器物材料（金属 / 木质 / 陶瓷 / 塑料） |
| 关键视觉 | 骨骼延展、肌肉鼓胀、毛发刺出、体型比例改变 | 材质光泽蔓延、柔软度消失、关节消失、轮廓几何化 |
| 终点 | **可动**的兽 / 兽人 | 通常**静止**的器物 |
| 生命感 | 增强（更野、更有力） | 抽离（变得更"死"） |
| 可逆 | 多可逆 | 多可逆 |
| 与谁的边界 | 靠近⑥进化（同族升级）与⑲恐怖异化（失控版） | 靠近④机械变形（无机↔无机）与⑤物品→人形（互逆） |

⚠️ **绝不能用粒子/光代替兽化的重构**——粒子化是⑮能量重铸的专属语法。兽化的重构材料**必须是身体本身**，观众要读到"这是生物在改"，不是"这是能量在重组"。

### 1.1 着装装甲化的两个子型（最易混淆，务必分清）

| 子型 | 过程 | 手法 | 节奏 | 锚点 | 代表 |
|---|---|---|---|---|---|
| **①-A 魔法少女型**<br>Mahou Shoujo | **闪帧替换 + 遮盖替换**：过程被装饰物遮住，观众"看见结果多于看见过程" | 丝带、花瓣、星光、羽毛、水泡、光带缠绕遮体；纯色人形轮廓先出现，服装再从轮廓"长出" | **极快**（整体 3-8s），但被拉成仪式化慢镜 | 变身道具（胸针/戒指/魔杖）+ 识别色 + 发型眼型 | 美少女战士、魔法少女小圆、光之美少女 |
| **①-B 装甲骑士型**<br>Henshin suit | **部件飞入 + 依次咬合**：过程完全可见，观众"看着装甲一件件穿上" | 装甲片自画外飞入、磁吸/卡扣/展开/覆盖依次锁定 | 中速偏快，咬合频率递增 | 腰带 / 变身器 + 识别色 + 眼灯 | 假面骑士、战队英雄 |

**区分关键**：①-A 靠**遮盖**（观众看不清但觉得很美），①-B 靠**咬合**（观众看得清每一件）。把①-A 写成①-B 会失去魔法少女的梦幻感；反过来则失去机械爽感。

> ①-A 与 ⑬纯换装 的区别：魔法少女有**身体本身的微妙变化**（身形比例、发型、瞳色变大）与**装饰物遮盖的仪式感**；⑬纯换装零身体变化、无仪式感。

### 1.2 恐怖异化（⑱）的判定与邻居

| 与谁的边界 | 区别 |
|---|---|
| vs ② 兽化 | 兽化**保留自我**、是能力或本能；恐怖异化**自我被侵蚀**、是不可控的丧失 |
| vs ⑪ 附身 | 附身是外来意识争夺控制权，本体仍在；恐怖异化是本体正在消失 |
| vs ⑯ 赛博格化 | 赛博格是主动改造、有功能逻辑；恐怖异化是被动侵蚀、无功能逻辑 |
| vs ⑱ 形态解放 | 解放是变强、爽；恐怖异化是变"非人"、代价是自我 |

**恐怖异化的三个必备情绪点**（缺一不像恐怖变身）：
1. **不可控**——主体在抵抗（手抓住门框、咬牙、想缩回手），但抵抗无效
2. **被观看/被感知**——给一个反应者（镜子里的自己、同伴的惊恐脸、自己的手在眼前变形）
3. **渐进不可逆**——每完成一步就回不去了（H1 在这里表现为"越陷越深"，不是"变成更强"）

## 2. 六个正交维度（快速定位用）

用户描述模糊时，按这六问定位。**前两问基本就能定类。**

| 维度 | 取值 | 判据 |
|---|---|---|
| **① 变化尺度**（关键） | 外观替换 / **有机重构**（物种改变）/ **无机化**（材质置换）/ 物种内进化 / 无机→有机 / 有机→无机 | 身体本身改没改？改成有生命还是没生命？ |
| **② 是否保留原本体**（关键） | 保留（拟态/附身）/ 覆盖（装甲）/ 消解重铸（能量化）/ 新增并列（分身/合体） | 变完之后"原来那个人"还在不在？ |
| **③ 过程可见性** | 渐变（狼人）/ 闪帧替换（魔法少女）/ 遮盖替换（装甲光效）/ 粒子解构（光重铸）/ 不可见（性别/退化） | 中间的变形过程要不要给观众看？ |
| **③-b 重构的材料**（②/③/⑮ 专用） | **生物组织**（骨肉毛爪）/ **器物材质**（金属木陶瓷）/ **能量粒子**（光与粒子） | 变的时候"材料"是什么？——决定特效能不能用粒子 |
| **④ 驱动方式** | 装置 / 咒语 / 情绪 / 外力 / 自主进化 | 是什么触发的？需不需要道具或动作起手？ |
| **⑤ 外部配件** | 有（腰带/变身器/能量源）/ 无 | 有没有一个实体装置参与？（有=天然锚点） |
| **⑥ 可逆与代价** | 可逆无代价 / 可逆有代价 / 不可逆 | 变完能不能变回来？付出什么？ |
| **⑦ 耗时** | 瞬时（闪帧）/ 渐进（多秒） | 决定要不要拆 clip（见 `04`） |

### 判定决策树

```
Q0 是主动获得力量，还是被动失去自我？
└─ 被动、违背意志、自我在消失 ──→ ⑲ 恐怖异化（★ 先问这条，问错全盘皆错）

Q1 身体本身改变吗？
├─ 否，只是加了层东西 ──→ Q2 加的是装备还是衣服？
│                        ├─ 装备/装甲 → Q2-1 过程怎么呈现？
│                        │   ├─ 部件一件件飞入咬合 → ①-B 装甲骑士型
│                        │   └─ 被丝带/花瓣/星光遮住再替换 → ①-A 魔法少女型
│                        └─ 只是衣服 → ⑬ 纯换装
└─ 是 ──→ Q3 变成的东西还有生命吗？
         ├─ 有生命 → Q3-1 是跨物种还是同族升级？
         │          ├─ 跨物种（人→兽/兽人） → ② 兽化【有机重构，不用粒子】
         │          └─ 同族升级             → ⑥ 进化（分多阶 → ⑫ 多段阶进）
         ├─ 没生命 → Q3-2 起点是什么？
         │          ├─ 人变器物/武器/器械   → ③ 物件化【无机化·材质置换】
         │          ├─ 器物变人形           → ⑤ 物品→人形（③的逆过程）
         │          └─ 器物变另一种器物     → ④ 机械变形
         └─ 不是"变成什么"的问题 ──→ Q3-3 是哪类变化？
                  ├─ 解构成光/粒子再重铸 → ⑮ 能量重铸【粒子是这一类专属】
                  ├─ 只是变大 / 变小     → ⑧ 巨大化 / ⑨ 退化幼化
                  ├─ 多个合成一个        → ⑦ 合体
                  ├─ 一个变多个          → ⑰ 分身增殖
                  ├─ 别人进我身体        → ⑪ 附身
                  └─ 换个性别 / 伪装     → ⑩ 性别转换 / ⑭ 拟态

补充判定：机械替换局部 → ⑯ 赛博格 ｜ 封印解开 → ⑱ 形态解放
```

## 3. 与相邻概念的边界（避免答非所问）

| 概念 | 判据 | 易混点 |
|---|---|---|
| **变身** | 主体自身形态改变 | 与"着装"的区别在身体改没改 |
| **变形** | 结构重组（机械 / 生理） | 偏无机或生理，不带"装备"语义 |
| **合体** | ≥2 体并一 | 与变身区别在多主体参与 |
| **进化** | 同物种升级 | 与变形区别在物种不变 |
| **召唤** | 外物召来，本体不动 | 与附身区别在谁主导 |
| **着装** | 仅加装备 | 与变身区别在无身体变化 |
| **形态切换** | 同体多预设态切换 | 与多段阶进近义，但弱层级 |
| **附身** | 外来意识控体 | 与变身区别在本体仍存活 |

## 4. 亚类 → 镜头语法索引

| 亚类 | 形态构建主语法 | 详见 |
|---|---|---|
| ①-B 装甲骑士型 | 部件飞入 + 依次咬合锁定 | `03 §3.1` |

| **③ 物件化** | **无机化**（材质置换 + 几何化 + 段落刚性化） | `03 §3.3` |
| ④ 机械变形 | 零件绕轴翻转 + 多机位展示结构 | `03 §3.4` |
| ⑤ 物品→人形 | 器物特征保留 + 拟人化生长（③的逆过程） | `03 §3.5` |
| ⑥ 进化 / ⑫ 多段阶进 | 光茧包裹 → 破裂挣脱 → 升阶 | `03 §3.6` |
| ⑦ 合体 | 零件向中心汇聚 + 对接咬合 | `03 §3.7` |
| ⑧ 巨大化 | 尺度对比 + 环境被撑开 | `03 §3.8` |
| ⑬ 纯换装 | 织物凭空生成 + 流动包裹 | `03 §3.9` |
| ⑮ 能量重铸 | 粒子解构 → 引导 → 重铸（**粒子是这一类的专属语法**） | `03 §3.10` |
| ⑯ 赛博格化 | 有机被机械逐段替换 | `03 §3.11` |
| ⑲ 恐怖异化 | 不可控侵蚀 + 抵抗无效 + 渐进不可逆 | `03 §3.13` |

其余亚类（⑨⑩⑪⑭⑱⑲⑰⑱）共用"局部替换 / 状态切换"语法，见 `03 §4` 通用替换模板。

⚠️ **会让身体发生可见重构的六个亚类最易混**，分野记牢：
**① 是穿上去（可脱）｜② 是变成另一种生物（自我还在）｜③ 是变成死物（材质置换）｜⑮ 是解构成能量再重铸（粒子专属）｜⑯ 是换掉一部分（主动、有功能）｜⑲ 是被吃掉（自我消失、不可逆）。**

## 5. 多亚类叠加的处理

现实中一个变身常叠了多个亚类（如"着装装甲 + 多段阶进 + 巨大化"）。处理原则：

1. **选一个主亚类**作为形态构建的语法主干（决定镜头怎么写）。
2. 其余作为**修饰层**，叠加到主干的某一拍上（例如巨大化放在 T3 定格之前）。
3. **不许在同一拍里同时走两套构建逻辑**——那会变成"部件在飞的同时身体也在长骨头"，模型必糊。

| 叠加组合 | 主干 | 修饰落点 |
|---|---|---|
| 装甲 + 阶进 | ① 着装装甲 | 阶进差异放在 T3 定格的形态细节 |
| 装甲 + 巨大化 | ① 着装装甲 | 巨大化放在 T2 末 / T3 前 |
| 兽化 + 阶进 | ② 兽化 | 每阶换一次重构的"收敛终点"（仍走有机重构，不换粒子） |
| 合体 + 机械变形 | ⑦ 合体 | 变形作为各部件的入场方式 |
| 能量重铸 + 装甲 | ⑮ 能量重铸 | 装甲在重铸的"引导"阶段出现 |
| 物件化 + 附身 | ③ 物件化 | 附身作为触发（T0），物化仍走材质置换 |
