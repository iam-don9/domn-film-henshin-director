# 02 · 四拍时间结构

> 这一层决定变身**有没有过程感**。
> 核心律：**解构慢、重组快、亮相静。**

---

## 1. 四拍模型

```
T0 触发激活 ──→ T1 解构剥离 ──→ T2 重组构建 ──→ T3 定格亮相
   蓄势·决意      撕裂·代价       凝聚·升阶       震慑·确立
   [锚点亮起]     [旧形态退场]    [新形态生长]    [完成态确立]
        └────────── 形态单向收敛，全程不回退（H1）──────────┘
```

| 拍 | 情绪任务 | 形态任务 | 观众在这拍读到什么 |
|---|---|---|---|
| **T0 触发激活** | 蓄势、决意 | 锚点启动、能量起 | "他要变了" |
| **T1 解构剥离** | 撕裂、代价、挣扎 | **旧形态退场**（关键：必须有明确消失帧） | "旧的正在没了" |
| **T2 重组构建** | 凝聚、加速、爽 | 新形态逐件生长锁定 | "新的正在长出来" |
| **T3 定格亮相** | 震慑、确立 | 完成态静止展示 | "成了" |

> **亚类差异 · T1 的四种走法**（不必强求"剥落"）：

| 亚类 | T1 实际发生什么 |
|---|---|
| ① 着装装甲化 | **包裹**——本体不消失，能量/装甲直接覆盖上来（假面骑士属此类） |
| ② 兽化 / ⑤ 进化 | **解构剥离**——旧形态褪去、茧壳崩裂 |
| ③ 机械变形 | **结构拆解并保留**——零件分离但不丢弃，为 T2 重组备料 |
| ⑭ 能量重铸 | **完全解构**——化为粒子（须保留人形轮廓数帧再散） |

**T1 的判定标准**：只要观众能明确读到"旧的正在退场、新的即将登场"，这一拍就成立——不论有没有剥落。

### 时长配比表（按总时长）

| 总时长 | T0 触发 | T1 解构 | T2 重组 | T3 亮相 | 说明 |
|---|---|---|---|---|---|
| **5s** | 0.6s | 1.2s | 2.2s | 1.0s | 重组占 44%，解构被压缩 |
| **10s** | 1.5s | 2.5s | 4.0s | 2.0s | 标准配比 |
| **15s** | 2.0s | 4.0s | 6.0s | 3.0s | 解构得以展开 |
| **30s** | 4.0s | 8.0s | 12.0s | 6.0s | 长变身，**必须拆 clip**（见 `04`） |

**总长越短，重组占比越高**——短片没时间展示挣扎，直接给结果。

## 2. 节奏律：解构慢、重组快、亮相静

| 拍 | 速度 | 为什么 |
|---|---|---|
| **T1 解构** | **慢**（B 类低幅度慢拍为主） | 变身的"代价感"在这。旧形态退场越沉，新形态越值钱。可给 A 类微升格（绑流动元素） |
| **T2 重组** | **快**（加速推进） | 爽感来源。部件连续咬合、结构连续生长，节奏递增，不许匀速 |
| **T3 亮相** | **静**（完成态静止） | 压迫感来源。**静 ≠ 停格**：环境仍在动（气场、粒子、衣摆、余光），主体定住 |

### 两种慢在变身里的用法（沿用打戏口径）

| | A 类 · 真放慢时间 | B 类 · 低幅度慢拍 |
|---|---|---|
| 用在 | T1 解构的关键剥离点、T3 亮相前的一瞬 | T0 蓄力、T1 挣扎、T2 咬合前的对准 |
| 要求 | 绑流动元素 + ramp in→snap back，**禁裸写**定格/顿帧/时间静止/子弹时间 | 画面照常动，只是幅度极小（气场涨、指尖颤、呼吸起伏） |
| 次数 | 短片 1 次，长片 1-2 次 | 每拍都该有 |

⚠️ T3 亮相的"静"**必须用 B 类**（主体定住、环境仍在动）。若写成 A 类停格，AI 视频会真的卡住画面。

## 3. 咬合一拍四段（变身的重音单元）

打戏的重音是"命中"，变身的重音是**锁定点**（部件咬合 / 结构闭合 / 光收束）。每个关键锁定点都要齐备四段：

```
① 接近：部件/能量沿明确轨迹飞向锁定位（带速度线与残影）
   ↓
② 对准：B 类慢拍，部件悬停在锁定位前一寸微调对正（"咔"之前的那一顿）
   ↓
③ 咬合锁定：卡扣咬死 / 能量环收束 —— ★ 重音在这
     配：一帧高光闪 + 环形冲击波外扩 + 镜头微震 + 卡扣处迸出火花/光屑
   ↓
④ 反馈：锁定后的连锁反应（相邻部件被点亮、装甲片连锁闭合、
     地面被余波掀起环形尘/水花、主体身上气场整体一涨）
```

**每个咬合的反馈不许复读**。十件装甲要有十种锁定方式：磁吸 / 卡扣 / 缠绕 / 嵌入 / 覆盖 / 展开 / 折叠 / 生长 / 凝聚 / 咬死。

**T2 的加速感**就来自咬合频率递增：前几件慢而清楚，后几件越来越快，最后几件几乎同时锁定收束。

## 4. ★ 形态单向收敛（H1 · 变身第一铁律）

**形态只能朝终态走，绝不回退。**

```
✅ 人 → 半装甲 → 全装甲 → 完成态
❌ 人 → 半装甲 → 退回人形 → 再变 → 卡住（AI 视频最常见）
```

- 正文**禁写**：退回原样、恢复人形、变回、消散重来、形态反复闪烁。
- 若剧情确实需要"变身失败/被打断"，那属于**另一个 clip**，且必须明确写清"这是中断不是回退"，并在下一个 clip 从中断处**继续向前**推进，不从头重来。
- 中途出现的"半形态"必须是**朝终态收敛的中间态**，不是新旧形态叠影（H2）。

**与打戏 T3「空间单向推进」的关系**：打戏是位置 A→B→C→D 不回原点；变身是形态 旧→半→新→完成 不回旧态。同一条律的两种投影。

---

## 5. 变化持续可见（H2 · 变身第二铁律）

变身戏最尴尬的失败是"看不出在变"。两条边界都要守住：

| ❌ 左边界：整帧静止 | ❌ 右边界：糊死看不见 |
|---|---|
| 主体定住不动、只有光在闪 | 一团光/粒子把主体完全盖住，中间几秒没有任何结构信息 |
| 违反"持续变化" | 违反"变化可见" |

**正确做法**：
- 每个 0.5s 至少有**一处可见的形态推进**（一件部件到位 / 一段身体完成重构 / 一层结构翻转）。
- 特效**做引导而非遮盖**：粒子沿身体流动指示"正在长"，而不是把人埋进光球里（H5）。
- 遮盖类特效（强闪光、能量幕）只能在**拍与拍的接缝**用一次，用来藏切换，**不能持续多秒**。

## 6. 多段阶进（二阶 / 三阶 / 最终形态）

| 规则 | 内容 |
|---|---|
| **每阶必须有可辨识的形态语言** | 阶与阶之间在轮廓、配色、部件数量、体量上至少有一项**明显跃迁**。观众要能一眼看出"又强了一阶" |
| **每阶独立走一次四拍** | 二阶不是一阶的延长，是**新一轮 T0→T3**（但 T0 可压缩为"锚点再亮"） |
| **阶数上限** | 短片（≤15s）**最多两阶**；30s 以上最多三阶。再多视觉语言必崩 |
| **代价递增** | 每升一阶，代价/负荷要升级（气场更暴、身体负荷更重、环境反应更大） |
| **收敛方向** | 每阶都是"更强的完成态"，不是"另一种形态"。最终阶 = T3 定格亮相 |

```
一阶 T0-T3 ──→ [锚点再亮] ──→ 二阶 T1'-T3' ──→ [锚点过载] ──→ 最终阶 T2''-T3''
                  ↑                                    ↑
              压缩版触发                          压缩版触发 + 更大代价
```

---

## 7. T3 定格亮相（收尾铁则）

- **就一下**：完成态确立 + 环境仍在动（气场收敛、粒子悬浮、衣摆余动、地面余波），主体定住，画面结束。
- 占时：5s 片 1s / 10s 片 2s / 15s 片 3s / 30s 片 6s。
- **之后零追加**：不补"缓缓转身""走向镜头""开口说话""远景拉远"。
- 镜头建议：正面中近景 或 低角度仰拍全身，配缓慢环绕 或 极慢推近（**镜头动、主体不动**）。
- 可叠**终结帧协议**（见打戏 `02 §5` 同源规则）：主色抽环境 + 保留人物细节 + 单色爆闪收尾。

> 想避免每条都单色染屏时的两个变体：
> ① 属性色爆闪收尾（贴角色识别色）
> ② 动量出画——余波/速度线漫过镜头瞬间收黑

## 8. 单拍内部的最小结构

每个拍内部再分三层，避免"一整拍只有一个大动作"的空洞：

```
起（这一拍从上一拍的余势接续）  →  承（主要形态推进）  →  转（一个意外/重音/加速点）
```

- **起**：必须接住上一拍的动势（打戏 T2 动势衔接同源）。上一拍末尾能量向内收，这一拍开头就向内收着起。
- **承**：这一拍的主体形态推进，占 60-70% 时长。
- **转**：一个让节奏产生变化的小事件（一件部件咬歪了被强行压正 / 能量突然暴涨 / 主体闷哼一声绷紧）——**这是让变身"有戏"而不是"放动画"的关键**。
