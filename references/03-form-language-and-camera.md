# 03 · 形态构建语法与运镜

> 这一层决定变身**长得好不好看、认不认得出是谁**。

---

## 1. 形态构建的两套词汇

所有亚类的形态构建都由两种基本动作组成，比例不同就形成不同亚类：

| | **解构**（T1） | **重组**（T2） |
|---|---|---|
| 语义 | 旧的退场 | 新的生长 |
| 动词 | 褪去、剥离、崩落、溶解、龟裂剥落、化为粒子、被抽离、熄灭 | 咬合、包裹、生长、翻转、嵌入、覆盖、凝聚、重铸、锁定 |
| 方向 | **向外扩散**（离开主体） | **向内收敛**（聚向主体） |
| 节奏 | 慢、顿挫、带代价 | 快、加速、带爽感 |
| 特效 | 碎屑外飞、旧色褪去、余烬飘散 | 粒子内聚、光带引导、能量环收束 |

**方向是关键**：解构向外、重组向内。写反了（解构时粒子往身体里吸）会让观众读不懂在变还是在散。

## 2. ★ 视觉锚点系统（H3 · 变身独有，最重要）

变身戏最大的认知风险：变完之后**观众认不出这是同一个人**。锚点是唯一的解药。

### 锚点选型（按优先级）

| 优先级 | 锚点 | 适用 |
|---|---|---|
| 1 | **变身装置**（腰带、手镯、变身器、核心） | 有外部配件的亚类（①⑥⑪⑭⑱） |
| 2 | **识别色 / 双色配色** | 全部亚类，**必选**，成本最低 |
| 3 | **眼部 / 面罩光** | 装甲、兽化、赛博格 |
| 4 | **标志部件**（披风、角、尾、翼、武器） | 兽化、进化、形态解放 |
| 5 | **身体轮廓剪影** | 巨大化、进化（靠外轮廓的家族相似性） |

### 锚点时序（三拍必到）

```
T0 触发 ──→ 锚点第一个亮起（"是他在变"）
T1 解构 ──→ 锚点全程可见，不被特效吞掉（"还是他"）
T2 重组 ──→ 锚点最后锁定 / 被新形态包住但留可见窗口
T3 亮相 ──→ ★ 锚点特写确认（"确认是他"）
```

### 锚点不灭的三条写法

1. **锚点不被遮盖**：粒子流、光效绕开锚点走，或锚点自身发光穿透特效。
2. **识别色不漂**：从 T0 到 T3，配色**只增不换**。新形态可以在识别色基础上加辅助色，不许整体系换色。
3. **T3 给锚点一个特写**：哪怕只有 0.3s，也要有一帧锚点特写完成"身份确认"。

## 3. 各亚类镜头惯例（含分镜范例）

### 3.1 装甲骑士型（①-B）
**语法**：锚点特写起 → 部件逐一飞入咬合 → 环绕接正面定格。
```
范例：中景正面，机械臂自画外递入胸甲，"咔"一声锁定（1.2s/件 × 4 件），
      镜头同步环绕 90°，最后正面中近景定格。
```
要点：部件**有来源**（从哪飞来）、**有次序**（先核心后四肢）、**有锁定反馈**（见 `02 §3` 咬合四段）。

### 3.2 兽化（②）

**语法**：**有机生物重构**——骨骼延展、肌肉鼓胀、毛发刺出、体型比例改变。**材料是身体本身，不是能量。**

```
范例：仰拍，手部指骨一节节伸长、指节反向弯折、指甲化为利爪（B 类慢拍，
      青筋暴起、额角冷汗）；脊柱弓起撑破衣背，肌肉束在皮下鼓胀游走，
      毛发自毛孔成片刺出（2s）；低角度仰拍整体轮廓在骨骼重排中重构为兽形。
```

要点：
- **❶ 绝不用粒子/光代替重构**——粒子化是⑮能量重铸的专属语法，套在兽化上会把它写成能量化，丢掉生物感。
- **❷ 重构的材料是生物组织**：骨、肉、毛、爪、牙、体型比例。观众要读到"这是身体在改"。
- **❸ 保留人形轮廓到最后**再完成兽化（H3），让观众认得出是谁。
- **❹ 代价走生物反应**：绷紧、闷哼、青筋、冷汗、呼吸急促、体温蒸腾的白汽。不走血肉路径（血肉属⑲恐怖异化 G2+）。
- **❺ 与⑲恐怖异化的运镜相反**：兽化给**仰拍 + 力量感 + 生长的爽**；恐怖异化给**俯拍 + 失控 + 被侵蚀**。同样是人变怪，镜头语言是反的。
- **❻ 与⑥进化的区别**：兽化是跨物种（人→兽），进化是同物种升阶。

### 3.3 物件化（③）

**语法**：**无机化——材质置换 + 几何化 + 段落刚性化**。人变成无生命的器物（武器 / 家具 / 器械 / 日常物品）。

```
范例：中景，右手自指尖起失去柔软度，金属光泽自指尖向手腕蔓延置换（1.5s）；
      指关节消失、前臂两段刚性化成一条直线；木纹/金属纹沿肩颈继续扩散
      （B 类慢拍，衣物在无变化处仍随呼吸起伏）；
      整体定格为一件静置于地的器物（T3，静止 + 尘埃落定）。
```

要点：
- **❶ 材质替换的边界必须可见**——光泽/纹理从某一点向外蔓延，观众看见"人正在变成什么材料"。边界看不见就变成"贴了层皮"。
- **❷ 有机→无机的三个信号**：柔软度消失、关节消失、轮廓向几何收敛。三者至少写两个。
- **❸ 终点通常是静止器物**（不可动），这是与④机械变形（终点是可动机体）的关键区别。
- **❹ 与⑤物品→人形互逆**：⑤是死物活化，③是人变死物。两者是同一条路径的正反方向。
- **❺ 保留一处"未完成"的人体细节**（一只还温热的手、一段还在起伏的衣料）能大幅提升戏剧性。
- **❻ 多数可逆**：还原必须写成**独立的一段**（另一轮 T0-T3），不是中途回退——H1 禁的是中途回退，不禁止设计上的可逆展示。

### 3.4 机械变形（④）
**语法**：零件绕轴翻转解构重组，多轴机位展示结构可信度。
```
范例：侧 45° 环绕，部件沿轴旋转咬合，快剪 3 帧/次（3s），
      穿插一个内部结构特写（齿轮/液压咬死）。
```
要点：❶ 变形步骤**不许跳帧**，中间态必须可读；❷ 给一次内部结构特写证明"这是机械不是魔法"；❸ 体量守恒感——变出来的和拆下去的看起来得是同一堆东西。

### 3.5 物品→人形（⑤）
**语法**：器物特征拟人化生长，器物形态保留为设计元素。
```
范例：中景，器物（如腰带/伞）悬浮，表面纹路流动成人脸轮廓，
      肢体自器物两端延展生长（2.5s），落地成人形，器物纹路留在服饰上。
```
要点：❶ **器物特征必须留痕**（纹路、材质、形状变成服装/配饰的一部分）；❷ 生长顺序从"器物本体"向外延展，不从虚空中凭空造人。

### 3.6 进化 / 多段阶进（⑥ / ⑫）
**语法**：光茧包裹 → 破裂挣脱 → 升阶，低角仰拍给挣脱感。
```
范例：全景，光茧自外向内收束包裹主体，A 类升格（碎屑仍流动），
      茧壳整片崩裂，主体破出抬手（2.5s），低角仰拍。
```
要点：❶ **挣脱感**是核心——茧是"壳"，主体是"破"，方向向外；❷ 每阶的茧形态要有差异（颜色、纹路、破裂方式）；❸ 升阶瞬间的爆发动静要大过上一阶。

### 3.7 合体（⑦）
**语法**：零件向中心汇聚 + 对接咬合，俯拍压缩空间。
```
范例：俯拍，3 股零件流自三方汇向中心，"轰"一声对齐咬死（2s），
      切仰拍全景看合体后的整体轮廓。
```
要点：❶ 汇聚有**时序**（不是同时抵达，是依次归位）；❷ 对接点给一次锁定重音；❸ 合体后必须有**整体轮廓确认镜**（仰拍/环绕），否则观众拼不出整体。

### 3.8 巨大化（⑧）
**语法**：尺度对比 + 环境被撑开。
```
范例：低角仰拍，主体自画面底部升起，前景建筑/树木被不断比下去（3s），
      最后一个超远景把主体与环境同框定格。
```
要点：❶ **必须有参照物**（建筑、树、其他人）在画面里被比小；❷ 环境要反应（地面震、结构被撑开、云被推开）；❸ 结尾给一次超远景确认尺度。

### 3.9 纯换装（⑬）
**语法**：织物凭空生成 + 流动包裹，B 类慢拍 + 柔光。
```
范例：中景侧，布料自领口/腰线流下裹住身体（2s），
      织物末端拖出光带，最后原地旋转定格。
```
要点：❶ 给织物一个**生成起点**（领口、腰带、指尖），别整件凭空出现；❷ 织物有流体感（拖尾、翻飞）；❸ 因为没有身体变化，**必须靠旋转/定格 pose 撑住"变身感"**，否则观感廉价。

### 3.10 能量重铸（⑮）
**语法**：粒子解构 → 引导 → 重铸，给结构信息。
```
范例：主体自下而上化为光粒子上浮（1.5s，粒子中仍可辨人形），
      粒子在锚点周围收束成新形态骨架（2s），实体自骨架生长填满。
```
要点：❶ **解构时保留人形轮廓**数帧再散，否则观众以为人没了；❷ 重铸要有"骨架先行、实体后填"的层次，给结构信息；❸ 忌一团光球糊到底。

### 3.11 机械融合 / 赛博格化（⑯）
**语法**：有机被机械逐段替换，强调质感对比。
```
范例：特写手臂，皮肤表面裂开露出金属内构，机械件自内向外推出咬合（1.5s），
      有机与机械的接缝处迸出火花与冷却雾。
```
要点：❶ 替换有**明确分段**（一段一段来，不是整体刷一层）；❷ 接缝处给质感反馈（火花、冷却雾、液压声）；❸ 机械部件要有功能暗示（不是贴片）。

### 3.12 魔法少女型（①-A）

**语法**：装饰物遮盖 + 闪帧替换 + 纯色轮廓长衣。**观众看到的是"结果的美"，不是"过程的机械"。**

```
范例：中景，变身道具（胸针）炸开成光带，丝带与花瓣自下而上缠绕遮住身体（1.5s），
      光最盛的一瞬硬切 → 纯白人形轮廓立于光中（0.5s，B 类慢拍），
      服装自轮廓的领口与腰线"长出"，丝带散开露出完成态（1.2s），原地旋转定格。
```

要点：
- **❶ 遮盖物必须有主题**（丝带 / 花瓣 / 星光 / 羽毛 / 水泡 / 音符），它是这一型的签名，不是通用光效。
- **❷ 纯色轮廓拍**是标志性一帧：先出现无细节的单色人形（白/粉/主色），服装再从轮廓上生成。
- **❸ 闪帧靠硬切**：变化发生在"光最盛的一瞬"，用硬切 + 强闪光遮盖替换，**不要写渐变 morph**（会糊）。
- **❹ 节奏是"快—慢—快"**：装饰物缠绕快 → 轮廓纯色拍慢（仪式感）→ 服装生成快 → 旋转定格。
- **❺ 身体有微妙变化**：身形比例、发型、瞳色会变（这是它区别于⑬纯换装的地方），但**幅度要小**，走"更闪耀"而非"换个人"。
- **❻ 锚点**：变身道具 + 识别色 + 发型眼型，三者全程可辨。

### 3.13 恐怖异化（⑲）

**语法**：不可控侵蚀 + 抵抗无效 + 渐进不可逆。**观众和角色一起"看着自己变成别的东西"。**

```
范例：特写手指，指尖皮肤下有异物沿指骨向上游走凸起（1.5s），角色用另一只手死死攥住手腕
      阻止它蔓延 —— 无效，凸起继续上行（B 类慢拍，闷哼、青筋、冷汗）；
      切镜中自己的惊恐瞳孔（0.4s）；
      手臂整体绷紧变形、轮廓撑破袖管（1s）；环境反应（灯闪、玻璃震、同伴后退）。
```

要点：
- **❶ 抵抗必须写，且必须无效**——手抓住门框 / 死攥手腕 / 咬牙 / 想缩回手。这是恐怖变身的灵魂，没抵抗就只是"变形"。
- **❷ 给一个"观看者"**：镜中的自己、自己的手在眼前变形、同伴的惊恐脸。恐怖来自"被看见"。
- **❸ 走"暗示"而非"展示"**：皮肤下游走、轮廓绷紧、关节反折、影子先变——**暗示比直给更恐怖**，也更好过审。
- **❹ 渐进不可逆**：每完成一步就回不去。H1 在这里表现为"越陷越深"，方向是**向下**而非"变强"。
- **❺ 环境替主体害怕**：灯闪、玻璃震、物体被撞翻、动物退避——用环境反应提恐怖度，不靠加血腥。
- **❻ 强度按 `05 §5.1` 分档执行**，不许默认最高档。

⚠️ 与 ②兽化 的镜头差异：兽化给"力量感"（仰拍、爆发、爽），恐怖异化给"失控感"（俯拍/贴脸特写、压抑、慢、无处可逃）。**同样是人变怪，运镜与节奏是反的。**

## 4. 通用替换模板（⑨⑩⑪⑭⑱⑲⑰⑱ 亚类）

这些亚类变化尺度小（退化、性别转换、附身、拟态、分身、形态解放），共用一套：

```
局部替换 / 状态切换语法：
  ① 触发点局部化（不是全身，是某一处开始：眼睛、手、影子）
  ② 局部变化扩散（变化从一个点蔓延到全身，有明确蔓延边界）
  ③ 完成态确认（一个能证明"变了"的行为或细节）
```

| 亚类 | 触发点 | 蔓延方式 | 完成确认 |
|---|---|---|---|
| ⑨ 退化幼化 | 全身轮廓收缩 | 由外向内压缩 | 与环境尺度对比（门把手变高） |
| ⑩ 性别转换 | 面部与身形 | 局部逐处变化（不是整体闪换） | 一个气质动作的切换 |
| ⑪ 附身 | 眼部 / 手 | 异化纹路自接触点蔓延 | 眼神变色的特写 |
| ⑭ 拟态 | 面部轮廓 | liquefy 式流动重塑 | 声音/举止的切换 |
| ⑰ 分身增殖 | 主体边缘 | 拉出、分离、实体化 | 多个体同时做一个动作 |
| ⑱ 形态解放 | 封印部位 | 封印破碎 → 能量外泄 → 形态膨胀 | 新形态的轮廓确认 |

## 5. ★ 特效不淹主体三律（H5）

| 律 | 内容 |
|---|---|
| ① **透明度递减** | 特效浓度随离主体距离递减——贴身处最淡，外围最浓 |
| ② **主体永实焦** | 重组期主体始终实焦；特效走前景虚化或背景层，不压在主体上 |
| ③ **每 0.5s 一帧纯主体** | 至少有一帧（或一个局部）是没有特效覆盖的清晰主体，让观众持续确认"这是谁、变成什么样了" |

### 特效挂载时序（按四拍）

| 拍 | 该有的特效 | 不该有的 |
|---|---|---|
| **T0** | 锚点小范围高亮、能量线起点（**克制**） | 全屏爆闪、满屏粒子 |
| **T1** | 旧色褪去、剥离碎屑外飞、半透明余烬（**不挡脸**） | 把主体整个糊住 |
| **T2** | 粒子流/光带沿身体引导部件移动，环状能量收束 | 无方向的随机火花 |
| **T3** | 一次爆发光环收束 + 静态余光 | 持续闪烁、反复爆闪 |

**特效是引导，不是遮盖。** 删掉全部特效后，形态推进仍然读得出来——这才算合格。

## 6. 运镜库

| 拍 | 推荐运镜 |
|---|---|
| **T0** | 锚点大特写起 → 拉远 / 低角度仰拍主体反应 / 缓慢推近 |
| **T1** | 环绕 + 低角度（展示剥离的各个面）/ 局部特写接力（手→臂→肩→脸） |
| **T2** | 环绕推进（速度渐快）/ 部件跟随特写 / 360° 高速环绕（升阶瞬间）/ 推轨逼近锚点 |
| **T3** | 正面中近景定格 / 低角度仰拍全身 / 极慢环绕（**镜头动、主体不动**）/ 慢推近至锚点特写 |
| **接缝** | 甩镜（whip pan）藏切换 / 强闪光遮盖替换 / 匹配剪辑（同方向同速接续） |

**运镜铁律**：
- 上一个镜头的运动方向，下一个镜头要**接住并延续**（打戏动势衔接同源）。
- T3 的"静"是**主体静、镜头动**（缓慢环绕/慢推），不是连镜头一起焊死。
- 长短镜头反差要大：T2 用快切堆密度，T3 用一个长镜定住。

## 7. 特写标点库（变身的节奏标点）

| 特写 | 专职 | 位置 |
|---|---|---|
| **锚点启动特写** | "要开始了" | T0 起手 |
| **局部变化特写** | 证明"真的在变"（指尖伸长、皮肤裂开、纹路蔓延） | T1 每次关键变化前 |
| **眼部/面部特写** | 代价与意志（瞳孔收缩、咬牙、汗滴） | T1 中段 |
| **部件飞入特写** | 卖速度与精密 | T2 部件咬合前 |
| **咬合锁定特写** | ★ 重音落点 | T2 每个关键咬合 |
| **内部结构特写** | 证明"可信"（机械/骨架） | T2 中段一次 |
| **整体轮廓确认镜** | 让观众拼出整体 | T2 末 / T3 前 |
| **锚点定格特写** | ★ 身份确认 | T3（**必给**） |

**一个完整的变身重音单元 = 部件飞入特写（因）→ 咬合锁定（连接）→ 连锁反馈（果）。**
别只写咬合不给反馈，否则锁定没有分量。
