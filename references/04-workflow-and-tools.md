# 04 · 工具能力与多 clip 拼接 workflow

> 这一层决定变身**能不能真的生成出来**。
> 最硬的事实：**没有任何工具能可靠地在单次生成里完成"人 → 非人"的极度形态突变。**

---

## 1. 先接受这个前提

| 误区 | 现实 |
|---|---|
| "写一条 15s 提示词，让他从头变到尾" | 单次生成只够承载**一个动作相位**。人→非人的完整突变**必须拆 clip** |
| "把人形和兽形设成首尾帧，中间让模型自己补" | **首尾帧会把中间过程锁死**，反而更容易卡在半途、出半形态叠影。本 skill **统一不用首尾帧** |
| "多给几张参考图就不会漂" | 参考图能稳住外观，**稳不住形态中途的重构逻辑**——重构逻辑只能靠拆 clip + 逐镜描述 |

**因此：变身的 workflow 优先级高于提示词。** 先决定拆几个 clip、参考图怎么配，再写每一段的话。

> ★ **本 skill 的一致性策略只有一条：双参考图（多图参照）。**
> 只用两张人物参照——**变身前的人物** 与 **变身后的形态**。不使用首尾帧机制。

---

## 2. 工具能力对照（供选型，能力随时间变，以实际账号为准）

> **选型标准：多图参照能力**（而非首尾帧）。本 skill 只用"变身前 + 变身后"两张人物参照，因此**只关心"能喂几张参考图、角色一致性稳不稳"**。

| 工具 | 多图参照能力 | 辅助机制 | 单次时长 | 备注 |
|---|---|---|---|---|
| **可灵 Kling** | 多图参考（约 4 张，O3 系） | 多元素编辑、运动控制 | 3-10s，V3 多镜头可更长 | 综合最稳；两张参照足够用 |
| **即梦 Seedance** | 全能参考（多图） | 自然语言运镜 | 单条 ≤15s，可拼接 | 与剪辑端衔接顺 |
| **Vidu** | 参考生（多图） | 动作迁移 | 2-8s，可延展 | 长时长延展有优势 |
| **Runway Gen-3 / Gen-4** | Reference 图 1-3 张 | Act-One 等 | 5/10s | 两张参照够用；不依赖其帧控制 |
| **Pika** | Scene Ingredients 元件 | **Pikaffects（融化/充气/爆炸等趣味变换）** | ≤10s | 趣味变身最强，偏短视频质感 |
| **Luma** | 角色参考 | 画面标注 | 5-20s 可延 | 推理式生成，慢但稳 |
| **Veo 3.1** | 3.1 多图（3.0 不支持参考图） | 物体增删 | 4/6/8s，可链式延长 | 原生音画同步；**必须用 3.1** |
| **海螺 MiniMax** | 主体参考 | 多种运镜指令 | 1080p 6s / 768p 10s | 长提示词理解与物理一致性口碑好 |

⚠️ 上表能力随版本快速变化，**落地前用你自己的账号各跑 1 组样片复核**再定 workflow。

## 3. ★ 三段式多 clip workflow（默认方案）

```
┌─ Clip A ─┐   ┌──── Clip B ────┐   ┌─ Clip C ─┐
│ 起态定格  │ → │   变身过程     │ → │ 终态定格  │
│ (人形)   │   │ T0-T2 分段生成 │   │ (完成态)  │
│ 静止/微动 │   │ 每 clip 一相位 │   │ 静止/微动 │
└─────────┘   └───────────────┘   └─────────┘
        ↑              ↑                  ↑
        └──── 三个 clip 共用同一组双参考图 ────┘
              （起态人物图 + 终态形态图）
```

| Clip | 内容 | 时长 | 生成方式 |
|---|---|---|---|
| **A 起态定格** | 变身前的人物，静止或微动（呼吸、眼神、抬手触发） | 1-3s | 图生视频，双参考图驱动 |
| **B 变身过程** | T0 触发 → T1 解构 → T2 重组，按相位再拆 1-3 个 sub-clip | 主体时长 | 图生视频 + 双参考图；每 clip 只承载一个相位 |
| **C 终态定格** | 完成态，静止 + 环境余动（气场、粒子、衣摆） | 1-3s | 图生视频，双参考图驱动 |

### 什么时候拆几个 clip

| 变身规模 | 建议 clip 数 | 说明 |
|---|---|---|
| 小变化（换装、局部异化） | 1-2 | 可单次完成 |
| 中等（穿装甲、能量重铸） | 3（A + B + C） | 默认方案 |
| 大（人→兽、机械变形、合体） | 4-6 | B 段按 T1 / T2 再拆，必要时 T2 内部再拆 |
| 巨大（人→巨像、多段阶进） | 6+ | 每阶独立走一轮 A-B-C |

### 拆 clip 的三条接缝规则（保证拼起来不跳）

| 规则 | 内容 |
|---|---|
| **① 构图同源** | 相邻 clip 的起手构图**同画幅、同机位、同光照**（不靠帧控制，靠描述词与参考图锁死） |
| **② 动势接续** | 上一 clip 结束时的运动方向/速度，下一 clip 开头**接住并延续**，不重新起手 |
| **③ 接缝藏切** | 接缝处用甩镜、强闪光、匹配剪辑（同方向同速）遮盖；或在接缝处安排一次"重音"（咬合锁定/爆闪）盖住切换 |

> 接缝最稳的做法：**让接缝正好落在一次强闪光或一次咬合重音上**，观众的眼被重音吸走，注意不到切换。

## 4. ★ 双参考图策略（H4 · 唯一的一致性手段）

**只用两张人物参照：变身前的人物 + 变身后的形态。不使用首尾帧。**

| 要点 | 规则 |
|---|---|
| **参照图 1 · 起态人物** | 正面 / 对称构图（最稳，模型不易扭曲）；姿态接近"变身起手式"；背景尽量干净 |
| **参照图 2 · 终态形态** | **完成态，不是过程态**。必须是变完的样子，不能用半形态 |
| **两图同源** | 同画幅、同机位、同光照、同背景（或同背景类型）。**差异只允许在"形态"上** |
| **只此两张** | 参照图不是越多越好。起态 + 终态两张足够；需要时可加**第三张锚点特写**（腰带/核心/变身器） |
| **中段声明** | 中间 clip 的提示词必须显式写"转化彻底完成""已完全变为……"，避免半形态残留 |
| **画风一致** | 两图必须是同一渲染质感（都要动漫，或都要写实）。混用必漂 |
| **不用帧控制** | 中间过程**交给提示词与拆 clip**，不交给首尾帧——首尾帧会把中间锁死 |

⚠️ **画风由参考图决定**（与打戏同律）：要动漫感，起态/终态设定图本身就必须是动漫渲染；写实图配再多 anime 关键词也救不回来。

---

## 5. 参考图锚定

| 规则 | 内容 |
|---|---|
| **每个 clip 都喂同一组参考图** | 跨 clip 的同一角色，参考图组必须一致（起态图 + 终态图 + 锚点特写图） |
| **角色描述词逐镜一致** | 外貌、服装、配色的描述词在每个 clip 里**逐字相同**，不许换措辞 |
| **光照词逐镜一致** | 换了光照描述，模型会重解角色 |
| **锚点单独出图** | 锚点（腰带/核心/武器）单独一张设定图，作为参考图之一，强化一致性 |

## 6. 失败模式与规避

| 失败 | 病因 | 规避原则 |
|---|---|---|
| **变到一半卡住** | 指望单次生成走完完整突变 | B 段按相位拆 clip，中段单独生成并给足时长 |
| **新旧形态鬼畜叠影** | 参照图没给终态完成态，或中段没声明"转化完成" | 参照图 2 必须是**完成态**；中段显式写"已彻底转化，无残留" |
| **主体漂移（变脸/换衣）** | 跨 clip 参考图不一致、描述词换了措辞 | 每 clip 同一组参考图，描述词与光照词逐镜一致 |
| **肢体扭曲** | 起态图姿态过于复杂/侧面 | 设定图优先正面、对称构图；单次只描述一个主要动作 |
| **过程潦草** | 时长不够 | 长变身必须拆 clip；单镜 ≤10s 只够一个相位 |
| **两态不像同一个人 / 不像同一场戏** | 两张参照图不同源（不同机位、光照、画风） | 同画幅、同机位、同光照、同渲染质感；终态用完成态 |
| **特效淹没主体** | 提示词里特效词比例过高 | 特效做引导不遮盖；每 0.5s 至少一帧纯主体 |
| **认不出是谁** | 没有锚点 | 定锚点，T0-T3 全程可见，T3 给锚点特写 |
| **亮相不帅** | T3 太短、没有定格 | T3 留足（10s 片至少 2s）；镜头动、主体不动 |
| **形态回退** | 提示词出现"退回/恢复/再变" | 形态单向收敛，正文禁回退词 |

## 7. 工具按戏分配（粗选）

| 需求 | 优先 |
|---|---|
| 趣味变身（融化、充气、爆炸式变形） | Pika（Pikaffects） |
| 电影级质感 + 靠双参照图稳一致性 | 可灵 / Vidu / 海螺 |
| 需要原生音画同步 | Veo 3.1 |
| 超长变身（30s+） | 即梦（可拼接）/ Vidu（可延展）/ Luma（可延长） |
| 需要对画面元素做精确标注 | Luma（画面标注） |
| 需要局部区域变换 | Pika（局部修改） |

## 8. workflow 交付格式（写进输出里）

生成方案要给用户一张可直接执行的表：

**参考图组固定为两张（+可选锚点图），所有 clip 共用，不设首尾帧。**

| Clip | 时间 | 承载相位 | 参考图组 | 提示词要点 |
|---|---|---|---|---|
| A | 0-2s | 起态定格 | 起态图 + 终态图（+锚点图） | 微动、触发前；描述词=起态人物 |
| B1 | 2-5s | T0 触发 + T1 解构前半 | 同上（同一组） | 锚点亮起、旧形态剥离 |
| B2 | 5-9s | T1 解构后半 + T2 重组 | 同上（同一组） | 形态构建；声明"已彻底转化" |
| C | 9-11s | T3 定格亮相 | 同上（同一组） | 描述词=终态形态；静止 + 环境余动 |
