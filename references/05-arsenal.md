## 4. 泛词黑名单（一个都不许出现）

| 禁用 | 替换为 |
|---|---|
| 变身、变化、变形 | 上方动词库取（咬合 / 剥离 / 重铸 / 生长 …） |
| 华丽、炫酷、帅气、震撼、炸裂、压迫感 | 直接写**形态推进、部件次序、尺度对比、环境反应** |
| 光芒四射、能量爆发、特效拉满 | 写清楚**什么光、从哪来、往哪去、照亮了什么** |
| 瞬间完成、一下子变完 | 写**中间态**：先怎样、再怎样、最后锁定在哪 |
| 退回原样、恢复人形、变回去 | 删（违反 H1）；确需"中断"则改写为"被外力打断"，下一段继续向前 |

## 5. 违禁词安全替换（100% 应用）

变身戏容易滑向"身体恐怖"，默认替换，**视觉冲击不减**：

| 禁 | 替换为 |
|---|---|
| 鲜血 / 流血 / 皮开肉绽 | 暗色能量残留 / 光屑外溢 / 结构分离处的粒子逸散 |
| 痛苦 / 惨叫 / 扭曲挣扎 | 绷紧、闷哼、额角沁汗、肌肉紧绷、呼吸急促 |
| 撕裂 / 皮肉剥离 | 结构分离、层片剥落、外壳剥离、旧形态褪去 |
| 恐怖 / 怪物化 / 异形 | 陌生的、非人的、重构中的 |
| 骨骼断裂 / 折断 | 结构重排、骨架延展、轮廓重构 |
| 死亡 / 消亡 | 沉入、静止、失去意识 |

> ⚠️ **粒子/光不是通用解——它是⑮能量重铸的专属语法。**

| 亚类 | 重构该走什么路径 | 严禁 |
|---|---|---|
| **② 兽化** | **生物组织**：骨骼延展、肌肉束鼓胀、毛发自毛孔刺出、指甲化爪、体温蒸腾白汽 | ❌ 粒子/光（会写成能量化，丢掉生物感） |
| **③ 物件化** | **材质置换**：金属/木质/陶瓷光泽自一点向外蔓延、柔软度与关节消失、轮廓几何化 | ❌ 粒子/光 |
| **⑮ 能量重铸** | **能量粒子**：解构成光粒子 → 引导 → 骨架先行、实体后填 | — |

> 血腥路径只有⑲恐怖异化在 G2 档才可能碰，其余一律不走。

### 5.1 ★ 恐怖强度分档（仅 ⑲ 恐怖异化 使用）

恐怖变身**不是不能写，是要先定档**。默认走 **G1**，用户明确要求更狠才上调。

| 档 | 名称 | 允许写 | 禁止写 | 适用 |
|---|---|---|---|---|
| **G0** | 暗黑奇幻 | 剪影、阴影、体型异化、压迫感、环境反应（灯闪/玻璃震/动物退避） | 任何组织细节 | 全年龄向暗黑、短视频平台保守口径 |
| **G1**（默认） | 惊悚暗示 | 骨骼轮廓错位、皮下凸起游走、关节反折、绷紧闷哼、冷汗颤抖、影子先变、轮廓撑破衣物 | 破裂、体液、伤口特写、器官 | **大多数恐怖变身**，效果最好也最稳 |
| **G2** | 强身体恐怖 | 结构重排、肢体增生、轮廓崩解、皮肤绷裂（写"绷裂"不写内容物）、异物破体而出（写"破出"不写是什么） | 血肉细节、器官、伤口内部 | 成人向 / 明确了尺度的项目 |
| **G3** | 极端 | —— | —— | **需先与用户确认平台边界**；多数平台会拒，不默认使用 |

**分档使用规则**：
1. 每次生成前先问（或按用户描述判定）恐怖档位，**写进输出的类型判定里**。
2. **暗示永远比直给更恐怖，也更好过审**——G0/G1 靠影子、声音、反应者、环境，不靠细节。
3. 提恐怖度靠**节奏与运镜**（拖长、贴脸特写、不给全景让人看清、反应者镜头），不靠加血腥。
4. 越界判定：若一句描写"去掉恐怖语境后依然不适"，就超档了，降一档重写。
