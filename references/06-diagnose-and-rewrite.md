# 06 · 诊断与改写（M2 补强模式）

> 用户拿来一段"变身提示词 / 分镜 / 已生成的视频描述"，要你补强。
> 先诊断、再改写，**不整段重写**——保住用户已有的有效部分。

## 输出格式（M2 固定）

```
一、【诊断表】  病症 | 证据（引用原句） | 病因 | 处方     ← 表格
二、【改写稿】  完整提示词正文 + 多 clip 方案表
三、【负面约束】6-8 条
```

诊断表按**严重程度分组**（🔴 致命 / 🟡 明显 / 🟢 优化），每条必须**引用原文中的具体句子**作为证据，不写"感觉不对"这种空判。

## 病症-病因-处方总表

| # | 病症 | 病因 | 处方 |
|---|---|---|---|
| 1 | **变到一半卡住 / 停在半形态** | 指望单次生成走完完整突变；重组段没设终点 | B 段按相位拆 clip；给重组设**明确终点帧**（最后一件咬合 / 光收束）；中段提示词写"转化彻底完成" |
| 2 | **新旧形态鬼畜叠影** | 参照图里给了半形态，或解构与重组交叉淡入 | 参照图只用**起态 + 终态完成态**两张；解构↔重组之间用**硬切或强闪光**过渡，不交叉淡入 |
| 3 | **主体漂移（变脸、换衣、换了个人）** | 跨 clip 参考图不一致、角色描述词换了措辞 | 每 clip 喂同一组参考图；外貌/服装/配色/光照描述词**逐镜逐字相同** |
| 4 | **特效淹没主体 / 一脸光看不清** | 特效词比例过高，且压在主体上 | 特效三律：透明度递减 / 主体永实焦 / 每 0.5s 一帧纯主体；特效改走引导（沿身体流动）而非遮盖 |
| 5 | **认不出变完的是谁** | 没有锚点，或识别色在变身中换掉了 | 定锚点（装置/识别色/眼部/标志部件），T0-T3 全程可见，识别色**只增不换**，T3 给锚点特写 |
| 6 | **看不出在变 / 只有光在闪** | 主体定住不动，只有特效在动（H2 左边界） | 每 0.5s 补一处可见形态推进；把"光在闪"改写成"某部件到位 / 某段身体完成重构" |
| 7 | **形态回退 / 变回去又变** | 违反 H1，正文出现"退回/恢复/再变"；或模型被首帧引力拽回 | 删除回退词；重排形态单向收敛路径；若是 img2video 首帧引力，把起态图与终态图的构图拉开 |
| 8 | **亮相不帅 / 结尾仓促** | T3 太短，或亮相后还在动 | T3 留足（10s 片至少 2s）；**主体静、镜头动**（缓慢环绕 / 慢推）；之后零追加 |
| 9 | **过程潦草 / 细节全跳** | 时长不够，一次想塞完所有相位 | 拆 clip；每个 clip 只承载一个相位并给足时长 |
| 10 | **肢体扭曲 / 中间态畸形** | 起态图姿态过于复杂；或单次描述了多个同时动作 | 设定图改正面、对称构图；单次只描述一个主要动作 |
| 11 | **类型判错**（把兽化写成换装、把合体写成进化） | 没过类型层 | 回 `01` 用 6 维度重新判定；按正确亚类的构建语法重写（部件逻辑 ≠ 骨骼重构 ≠ 结构翻转） |
| 12 | **变形步骤跳帧 / 机械变形不可信** | 中间态没给 | 补中间态；给一次内部结构特写（齿轮/液压）证明可信；体量守恒（拆下去的=变出来的） |
| 13 | **每阶长得都一样**（多段阶进） | 阶与阶之间没有形态语言差异 | 每阶在轮廓/配色/部件数/体量上至少一项**明显跃迁**；代价递增；短片最多两阶 |
| 14 | **纯换装显得廉价** | 零身体变化，又没撑住变身感 | 给织物生成起点（领口/腰线/指尖）；织物有流体拖尾；结尾靠旋转或定格 pose 撑住 |
| 15 | **能量重铸变成一团光球** | 解构时人形轮廓丢失，重铸没给结构信息 | 解构时**保留人形轮廓数帧**再散；重铸走"骨架先行、实体后填"的层次 |
| 16 | **咬合反馈复读**（每件都是"咔+火花"） | 缺乏变化 | 十件装甲十种锁定方式：磁吸 / 卡扣 / 缠绕 / 嵌入 / 覆盖 / 展开 / 折叠 / 生长 / 凝聚 / 咬死 |
| 17 | **恐怖变身太恶心 / 不够恐怖** | 没定恐怖强度档；或靠血腥堆恐怖 | 按 `05 §5.1` 先定 G0-G2 档（默认 G1）；提恐怖度靠**暗示 + 节奏 + 反应者镜头**，不靠加细节；删掉"去掉恐怖语境仍不适"的句子 |
| 18 | **恐怖变身写成了兽化**（只有变形没有失控） | 没写"抵抗与无效"、"被观看"、"不可逆" | 补三个必备情绪点：抵抗但无效 / 一个观看者（镜中自己、同伴脸）/ 每步不可逆；运镜改为俯拍与贴脸，不要仰拍爆发 |
| 19 | **魔法少女写成装甲咬合 / 写成纯换装** | ①-A 与 ①-B、⑬ 三者混淆 | ①-A 走**装饰物遮盖 + 闪帧硬切 + 纯色轮廓长衣**；必须有主题遮盖物（丝带/花瓣/星光）与纯色轮廓拍；身体有微妙变化但幅度小 |
| 20 | **兽化写成能量重铸**（人变成一团光/粒子再重组） | 粒子化是⑮能量重铸的专属，错用在②兽化上 | 兽化改走**生物组织**：骨骼延展、肌肉束鼓胀、毛发自毛孔刺出、指甲化爪、体温蒸腾白汽；删掉全部粒子/光重构描写 |
| 21 | **兽化与物件化混为一谈** | 两者在旧表里同属一格，语法混淆 | ②兽化=有机→另一种有机（终点可动、有生命感）；③物件化=有机→无机（材质置换、关节消失、终点静止器物） |

## 常见误诊提醒

| 用户说 | 可能不是 | 真正病因 |
|---|---|---|
| "特效不够炸" | 特效量不够 | 形态推进没写清楚（H2），加特效只会更糊 |
| "变不彻底" | 提示词没写"完全变身" | 没拆 clip，单次承载了过多相位 |
| "不够帅" | 造型问题 | T3 太短 / 没有锚点特写 / 亮相后还在动 |
| "人物变了" | 一致性约束没写 | 跨 clip 描述词换了措辞，或识别色在变身中漂了 |
| "太慢了" | 时长太长 | 解构与重组节奏相同（缺"解构慢重组快"的落差） |
| "不够吓人" | 血腥程度不够 | 缺暗示与反应者镜头，或没给"抵抗无效"的戏 |

## 改写四步

```
1. 定位  ── 通读原稿，先判类型（01），再对照总表打标，标出证据句
2. 分层  ── 判断病在哪一层：类型层（01）/ 时间层（02）/ 形态层（03·04）
          ⚠️ 先修类型层，再修时间层，最后才动特效与运镜
3. 重写  ── 保留用户已有的造型设定与世界观，只替换病变段落，不整段重写
4. 回读  ── 用 05 §7 速查表过一遍；四拍连起来读，看形态是否单调收敛、是否有可见推进
```

## 改写稿的分寸

- **保住用户的原创设定**：角色名、造型、世界观、变身器设定——不动。
- **只替换病变段落**，并在诊断表里说明"改了哪一句、为什么"。
- 用户只要"改这几处"时，就只改这几处，**不顺手全篇翻新**。
- 改完给**完整可复制的正文 + 多 clip 方案表**（不要让用户自己拼贴 diff）。
