## 2. ①【类型判定】

```
亚类：着装装甲化（①）
判定依据：
  变化尺度   = 外观替换（身体未改，外覆装甲）
  是否留本体 = 覆盖（人在装甲内）
  过程可见性 = 遮盖替换（部件飞入咬合）
  驱动方式   = 装置（腰带）
  外部配件   = 有 → 锚点 = 腰带核心
  可逆代价   = 可逆无代价
  耗时       = 渐进
叠加修饰：多段阶进（二阶），落点 = T3 前的形态细节差异
核心看点：部件依次咬合的仪式感
易砸点  ：光效堆砌、没有"穿上去"的咬合逻辑
```

---

## 3. ②【四拍时间轴】

用 ASCII + 短表，不写散文：

```
T0 触发 0-1.5s ─→ T1 解构 1.5-4s ─→ T2 重组 4-8s ─→ T3 定格 8-10s
  腰带核心亮起     旧装束褪去剥离    胸甲→肩→臂→腿    完成态定立
  仰拍+锚点特写    环绕+局部接力     逐件咬合加速     极慢环绕·主体不动

咬合序列：胸甲(磁吸) → 肩甲(展开) → 臂甲(缠绕) → 腿甲(折叠) → 头盔(覆盖)
          ↑ 每次反馈不同，不复读
锚点时序：T0 亮起 → T1 全程可见 → T2 最后锁定 → T3 特写确认
```

## 4. ③【多 clip 方案表】（M1 必给）

**所有 clip 共用同一组双参考图（起态人物 + 终态形态，+可选锚点图），不使用首尾帧。**

| Clip | 时间 | 相位 | 参考图组 | 提示词要点 |
|---|---|---|---|---|
| A | 0-1.5s | 起态定格 | 起态图 + 终态图（+锚点图） | 微动、触发前；描述词=起态人物 |
| B1 | 1.5-4s | T0 + T1 | 同上（同一组） | 锚点亮起、旧形态剥离 |
| B2 | 4-8s | T2 | 同上（同一组） | 形态构建；声明"已彻底转化" |
| C | 8-10s | T3 | 同上（同一组） | 描述词=终态形态；静止 + 环境余动 |

## 5. ④【分镜提示词】格式规范

- 按时间顺序，**连续覆盖 0.0 → 总时长，不重叠、不留空档**。
- 每个镜头开头：`[起止秒]` + 景别/机位 + 摄影机怎样看当前形态推进，随后直接写**形态变化、部件次序、当下结果**。
- **先定 workflow（拆几个 clip）再写提示词**；每个 clip 的正文可独立成段，段首标注 clip 编号。
- 长镜头只围绕**一个主要形态推进**展开；短镜头只抓**一个关键变化**（一次咬合、一次剥离）。
- 落地、转身、呼吸这类过渡**不单独成镜**。
- **T3 定格亮相写成一整镜**：主体定住 + 镜头极慢环绕/慢推 + 环境余动，**之后不切镜、不追加**。

### 图片标注（仅多图输入时）

每个角色 / 形态在正文**第一次出现时**带 `@图N`，紧贴名称**前面**：`@图1少年`、`@图2装甲形态`。编号按用户给图顺序，首次标注后不再重复。

### 正文语言（简单利落 · 像在现场讲戏）

```
✅ 每句提供一个能直接拍出来的新画面：形态推进 / 部件次序 / 镜头变化 / 环境反应
✅ 连续动作用短句串起来：顿号 + 具体动词
✅ "因部件咬合带起环形气浪"这类把效果与动作绑在一起的短因果句 —— 可以用
❌ 解释上一句的话 —— 删
❌ 发力原理 / 能量传递的抽象解释 —— 删
❌ 招式名、招式体系堆砌 —— 删（除非用户要求标注）
❌ 坐标、数组、JSON、自检、内部分析 —— 一律不出现
```

**交付正文必须清除全部自查编号**，只保留 `[时间戳]` 与 `[反馈]`，是一段纯净连续文本。

## 6. 字数契约

| 总时长 | 正文下限 | 通常区间 | clip 数 | 关键变化点下限 |
|---|---|---|---|---|
| 5s | 300 字 | 400-600 | 1-2 | 6 |
| 10s | 600 字 | 800-1100 | 2-3 | 12 |
| 15s | 900 字 | 1100-1500 | 3-4 | 18 |
| 30s | 1600 字 | 2000-2800 | 5-7 | 32 |

**关键变化点**：一次部件咬合 / 一段身体完成重构 / 一次结构翻转 / 一次尺度跃迁，各算一个。
（定义同打戏"有效动作节点"：同质重复只算 1 个，纯状态不算。）

**字数不足 = 形态推进没写够，去补部件次序与重构细节，不注水。**
**字数超出 = 删重复效果、无变化的句子，不删形态推进。**

## 7. ⑤【负面约束】写法

**只写 6-8 条**，只负责**画面稳定性**，不复述内部规则：

| ✅ 该写 | ❌ 不该写 |
|---|---|
| 起态/终态外形、配色、锚点部件一致 | 内部四拍流程、导演方法 |
| 识别色不漂移（只增不换） | 规定角色必须重复哪些动作 |
| 身体结构稳定（部件数量/位置/连接） | 空泛质量词（"高质量""不要模糊"） |
| 形态不回退、不出现半人半兽残留 | 复述变身类型学 |
| 锚点全程可见、不被特效完全遮盖 | 限制尚未决定的创意答案 |
| 画风与渲染质感锁定 | 复述多 clip 工作流细节 |

**模板（按需取 6-8 条）**：
```
1. 同一角色起态与终态保持同一识别色与标志部件，配色只增不换
2. [锚点部件]全程清晰可见，不被能量、粒子或闪光完全遮盖
3. 装甲/部件数量与连接关系稳定，不新增或缺失部件，不出现悬空碎片
4. 身体结构完整，不出现肢体扭曲、额外肢体、部件穿模或融合变形
5. 变身过程中不出现旧形态与新形态的叠影，任何时刻只有一种形态在场
6. 面部特征与眼灯细节清晰可辨，不被特效或遮挡覆盖
7. 画风与渲染质感全程统一：[四要素画风句]
8. 画面持续变化，无静止帧、无画面冻结，形态单向朝终态推进
```

## 8. 交付前自检（内部执行，不输出）

```
□ 类型已判定（19 亚类之一；① 需分清 A 魔法少女 / B 装甲骑士；②兽化与③物件化不得混为一谈），镜头语法与亚类匹配
□ 恐怖强度档位已定（若属⑲恐怖异化）；魔法少女类已按闪帧+遮盖手法写（若属①-A）
□ 重构材料对路：②兽化走生物组织（无粒子）／③物件化走材质置换（无粒子）／⑮能量重铸才用粒子
□ 锚点已定，T0 亮起 / T1 可见 / T2 锁定 / T3 特写 四拍齐全
□ 四拍齐全：T0 触发 / T1 解构（含旧形态明确消失帧）/ T2 重组 / T3 定格
□ 节奏律：解构慢、重组快、亮相静；T3 是主体静镜头动（非停格）
□ 形态单向收敛，零回退词，无半形态残留
□ 每 0.5s 至少一处可见形态推进；无整帧静止，也未被光球糊死
□ 咬合四段齐备（接近→对准→锁定→反馈），且每次反馈不复读
□ 特效三律：透明度递减 / 主体永实焦 / 每 0.5s 一帧纯主体
□ 多 clip 方案表已给：每 clip 相位/共用参考图组/提示词要点清晰；接缝三规则满足
□ 双参考图同源（起态+终态两张，不用首尾帧）；两图同画幅同机位同光照同渲染，中段声明转化彻底
□ 违禁词扫描清零；血腥路径仅⑲恐怖异化 G2 档可碰，其余一律不走
□ 零泛词；动词全部来自弹药库
□ 时间戳连续覆盖不重叠；T3 之后零追加
□ 字数达标；正文无编号、无表格、无 JSON、无内部分析
```
